# 網站音量倍率控制器 v5.0.0

先把太大聲的網站調低，再用網頁播放器原本的音量滑桿微調。

**目前輸出音量值 = 播放器音量 × 網站倍率**

例如：網站倍率 20%、播放器滑桿 50%，輸出就是 10%。播放器滑桿拉到 100%，輸出最多為 20%。

## 安裝並保留上一版

1. 解壓縮 `marumaru-volume-controller-v5.0.0.zip`。
2. 開啟 `chrome://extensions` 或 `edge://extensions`，開啟「開發人員模式」。
3. **停用 v4.1.5，保留它的安裝與資料夾。** 兩個版本同時啟用會互相干擾。
4. 選擇「載入未封裝項目」，選取新版包含 `manifest.json` 的資料夾。
5. 重新整理已開啟的影音頁面，清除舊版已注入的控制程式。

要切回上一版：停用 v5、啟用 v4.1.5，再重新整理影音頁面。

這是獨立新版，請不要覆蓋舊資料夾。v5 使用自己的網站倍率記錄，不會把 v4 的固定音量自動轉成倍率；第一次使用預設為 100%。

## 使用方式

- 開啟太大聲的網站，從擴充功能面板降低「網站倍率」，例如 20%。調整後自動保存。
- 平常直接使用網站播放器的音量滑桿、快捷鍵和靜音功能。
- 面板分別顯示播放器音量、網站倍率和目前輸出。開啟面板時約每半秒更新一次。
- 同 hostname 的分頁共用網站倍率，但每個播放器自己的音量獨立。例如分頁 A 播放器 50%、分頁 B 80%，倍率均為 20%，輸出分別是 10% 與 16%。
- 倍率為 0% 代表網站靜音。播放器滑桿仍可移動；提高網站倍率後才有聲音。
- 「恢復 100%」或刪除該網站記錄會解除校正，恢復播放器自己的音量。同網站已開啟的分頁也會更新。
- 「清除全部」只清除 v5 的倍率記錄。

## 與 v4.1.5 的差別

| 行為 | v4.1.5 固定音量版 | v5.0.0 倍率版 |
| --- | --- | --- |
| 擴充功能的設定 | 固定的輸出音量 | 網站音量倍率 |
| 網頁播放器滑桿 | 被固定音量覆蓋 | 保留播放器值，按比例輸出 |
| 網站設定 20%、播放器 50% | 輸出維持 20% | 輸出 10% |
| 記憶方式 | 分頁固定值與網站預設 | 網站倍率自動保存，各播放器自行調音量 |
| 面板資訊 | 控制音量 | 播放器、倍率、輸出三項分開顯示 |

## 支援範圍與限制

- 以透過 JavaScript 讀寫 `HTMLMediaElement.volume` 的網頁播放器滑桿為主要支援對象。提供播放器未縮放的讀值，避免滑桿跳回實際輸出位置，也避免播放器反覆讀寫時重複縮小音量。
- 追蹤一般 HTML video/audio、`new Audio()`、未插入 document 的媒體、動態新增媒體和開放式 Shadow DOM。跨網域 iframe 使用最上層網站的倍率。
- **瀏覽器原生 `<video controls>` 音量控制列直接操作底層音量，其旋鈕可能顯示縮放後的值。這類原生控制列不能保證和網站 JavaScript 自訂滑桿一樣維持完整 0–100% 的視覺位置。**
- 純 Web Audio、部分封閉 Shadow DOM、未注入腳本的頁面，以及刻意改寫原型或繞過音量屬性的播放器不在完整控制保證範圍。
- 初始化讀取設定前，已追蹤的媒體暫時靜音。讀取失敗會逾時重試；持續失敗時面板提供提示。
- 不提供 100% 以上放大，也不是瀏覽器層的整個分頁靜音。面板顯示的是媒體音量值，不是喇叭分貝或系統音量測量。
- 網站倍率儲存在本機 `chrome.storage.local`，以 hostname 區分；沒有外部資料傳輸。

## 驗證

32 項實際 Chrome 擴充功能檢查通過，使用獨立暫存設定檔和本機測試頁。

涵蓋真實鍵盤操作網頁滑桿、50% × 20% = 10%、滑桿與播放器儲存值維持未縮放數值、避免重複衰減、動態與跨網域媒體、0% 靜音、面板即時顯示、自動保存、儲存失敗提示、重新整理、多分頁獨立播放器音量，以及舊資料保留。

測試使用 Chrome 152.0.7977.76，實際載入 manifest、MAIN／ISOLATED 腳本、service worker 和 popup，使用真實 Chrome storage API。另注入一次儲存失敗以驗證錯誤處理。實際輸出數值從隔離執行環境讀取底層原生 volume，沒有把播放器的邏輯讀值當成輸出值。

尚未完成線上 Marumaru／YouTube 站點與實體喇叭輸出驗證。測試關閉實體聲音，以媒體播放狀態與音量值判定。

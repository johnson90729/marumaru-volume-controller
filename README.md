# 多網站音量記憶控制器 v4.1.4

Chrome／Edge Manifest V3 擴充功能，以擴充功能設定控制網站的 HTML 影音音量，並保留各分頁的獨立設定。

## 音量規則

- 在擴充功能面板調整目前分頁的音量。設為 0% 時，影片滑桿拉到 100%、按音量快捷鍵或取消播放器靜音，都不能把媒體音量提高。
- 已設定音量時，網站播放器的滑桿不再覆蓋擴充功能設定，也不會被存成新的分頁音量。要改變音量，請使用擴充功能面板。
- 按「將目前音量設為網站預設值」會儲存預設，並立即套用到目前分頁。
- 新分頁讀取網站預設；從擴充功能調整的分頁音量在重新整理後保留，且不會改變其他分頁。
- 尚無網站預設或分頁設定時，不限制播放器音量。清除目前網站記錄會解除目前分頁的限制。
- 播放器本身的靜音功能仍可使用；擴充功能不會強制取消播放器靜音。

## v4.1.4 修正與更新

- 移除「手動操作播放器時允許覆蓋音量」的規則，修正擴充功能 0%、影片調成 100% 後出聲的問題。
- 0% 使用精確的零值，不再容許小於誤差門檻的微小音量。
- 打開面板時，不再用 v2/v3 舊資料覆蓋已存在的網站預設，也優先顯示擴充功能控制值。
- 儲存網站預設時會同步套用目前分頁；無法連接分頁時明確提示尚未套用。
- 升級後不沿用舊版的暫存分頁音量，避免舊版從播放器記下的 100% 蓋掉網站預設 0%。網站預設會保留；需要的個別分頁音量可重新從面板設定。

更新方式：在 `chrome://extensions` 或 `edge://extensions` 重新載入本擴充功能，確認版本為 **4.1.4**，再重新整理影片分頁。已開啟的頁面需要重新整理，才會使用新程式。

## 安裝

1. 開啟瀏覽器的擴充功能管理頁。
2. 開啟「開發人員模式」。
3. 選擇「載入未封裝項目」，選取本資料夾。
4. 重新整理已開啟的影音分頁。

## 儲存與支援範圍

- 網站預設儲存在 `chrome.storage.local`，以 hostname 區分，例如 `www.youtube.com`。不同子網域使用不同預設。
- 分頁音量儲存在 `chrome.storage.session`，以 tabId 與 hostname 區分，關閉分頁後清除。不會傳送到外部服務。
- 支援一般 HTTP／HTTPS 網頁、動態新增的 HTML `<video>`／`<audio>` 與跨網域 iframe。
- 在頁面主執行環境攔截音量寫入，並在媒體事件、YouTube 頁面切換與新播放器建立時補套音量。
- 尚未讀到本機設定前，以及完全使用 Web Audio API、封閉 Shadow DOM 或其他非標準媒體路徑的播放器，不保證控制。這不是作業系統層級的分頁靜音。
- 音量範圍為 0–100%，不放大原始音量。

## 回歸測試

執行 `python tests/browser_regression.py`，需要 Chrome、Python 與 `websocket-client`。

測試使用獨立暫存 Chrome 設定檔、真實 DOM、可信任的滑鼠與鍵盤輸入、分離的 MAIN／ISOLATED 執行環境，以及模擬的擴充功能儲存與訊息介面。
涵蓋播放器調到 100% 時維持零音量、換片、延遲初始化、舊記錄處理、分頁獨立性與實際面板程式。
本機測試不等於已完成線上 YouTube 或喇叭輸出的端到端驗證。
